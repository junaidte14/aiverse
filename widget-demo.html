🤖 AIVerse Chat Widget Demo

This page demonstrates how to embed the AIVerse chat widget on any website.

📋 Basic Usage

<!-- Include the widget loader script -->
<script src="http://localhost:3000/widget-loader.js"></script>

<!-- Initialize the widget -->
<script>
    new AIVerseWidget({
        collection: 'my-docs',
        guestAllowed: true,
        title: 'Help Assistant'
    });
</script>

⚙️ Configuration Options

collection (string): RAG collection name for document search
collection: 'my-docs'
provider (string): AI provider (groq, openai, anthropic)
provider: 'groq'
model (string): AI model name
model: 'llama-3.3-70b-versatile'
guestAllowed (boolean): Allow unauthenticated users
guestAllowed: true
initialMessage (string): First message from assistant
initialMessage: 'Welcome! How can I help?'
primaryColor (string): Widget theme color (hex)
primaryColor: '#9333ea'
position (string): bottom-right or bottom-left
position: 'bottom-right'
title (string): Widget header title
title: 'AI Assistant'

🎯 Use Cases

1. Documentation Assistant (RAG-enabled)

new AIVerseWidget({
    collection: 'product-docs',
    title: 'Documentation Helper',
    initialMessage: 'Ask me anything about our product!',
    guestAllowed: true
});

2. Customer Support (Login required)

new AIVerseWidget({
    title: 'Customer Support',
    guestAllowed: false,
    primaryColor: '#0066cc'
});

3. Code Assistant (GitHub repo RAG)

new AIVerseWidget({
    collection: 'react-codebase',
    title: 'Code Assistant',
    initialMessage: 'Ask me about the React codebase!',
    primaryColor: '#61dafb'
});
